# Live Editing Session Plan - National Agricultural Biotechnology Research Center (NABRC)

This plan outlines the steps for the live editing session to refine and enhance the NABRC website.

## Phase 1: Infrastructure & Ready State
- [x] Audit existing codebase (App, Navbar, Footer, Pages).
- [x] Verify all routes and component connections.
- [x] Create this `plan.md` to establish the workflow.

## Phase 2: Immediate Enhancements (Proposed)
- [ ] **Research Page**: Implement real-time search filtering in addition to category tabs.
- [ ] **Publications Page**: Add sorting options (Newest vs. Oldest) and enhance search.
- [ ] **Contact Page**: Add a simple map placeholder or real Google Maps embed.
- [ ] **Navbar**: Implement a sticky glass-morphism effect that changes color on scroll.
- [ ] **Mobile Experience**: Refine the mobile menu with staggered entrance animations for links.

## Phase 3: Interactive Features
- [ ] **News Feed**: Implement a "Load More" or pagination for news items.
- [ ] **Gallery**: Add a lightbox effect for viewing high-resolution images.
- [ ] **Service Request**: Transform the "Request Service Details" into a modal form.

## Phase 4: User Directed Edits
- [ ] Await specific instructions from the user for any layout, content, or styling changes.
- [ ] Apply changes live to the requested files.
- [ ] Validate each build to ensure no regressions.

## Technical Stack
- React 19, Vite, Tailwind CSS
- Framer Motion for animations
- Lucide React for iconography
- Sonner for notifications
